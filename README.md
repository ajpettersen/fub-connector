# Follow Up Boss connector for Claude

A small private service that lets Claude read and write AJ's own Follow Up Boss account. It has no outside dependencies: Node 20+ only.

## What Claude can do with it

| Tool | What it does |
|---|---|
| `search_people` | Find contacts by name, email or phone, or everyone with a tag (e.g. PieDay2025) |
| `get_person` | One contact's details |
| `get_recent_activity` | Recent notes, calls and texts, plus the date of the latest touch |
| `list_tasks` | Open tasks, for everyone or one contact |
| `add_note` | Add a note to a contact |
| `log_call` | Log a call with a note and outcome |
| `create_task` | Create a follow-up task with a due date |
| `update_person_tags` | Add tags to a contact. Existing tags are always kept |

It never deletes anything, and never removes a tag. Set `READ_ONLY=true` to switch off the write tools.

## Deploy on Railway

1. **Put the code on GitHub.** Create a new **private** repository named `fub-connector` and upload `server.js`, `package.json` and this `README.md`.
2. **Create the Railway service.** In Railway, start a new project and deploy from that GitHub repository. Railway detects Node and runs `npm start`.
3. **Add the variables** on the service's Variables tab:
   - `FUB_API_KEY`: your API key from Follow Up Boss (Admin > API). Use the key from **your own** Follow Up Boss account, not Pemberton's company account.
   - `CONNECTOR_TOKEN`: a long random string of at least 24 characters, for example one generated by your password manager. Letters and numbers only.
   - `READ_ONLY` (optional): `true` if you want to start with read access only.
4. **Give it a public address.** In the service's networking settings, generate a domain. Open it in a browser and you should see "Follow Up Boss connector is running."
5. **Connect it to Claude.** Add a custom connector in Claude's connector settings with this URL (no OAuth details needed):

   `https://<your-railway-domain>/mcp/<your CONNECTOR_TOKEN>`

## Keep it private

- The connector URL contains your token, so treat the whole URL like a password. Don't share it or paste it into documents.
- Your API key lives only in Railway's variables. It is never in the code or in Claude's chats.
- To cut off access at any time, change `CONNECTOR_TOKEN` in Railway; the old URL stops working right away.
